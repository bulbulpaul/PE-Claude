# 要件定義書

## 概要

このプロジェクトは、現在OpenAI GPTを使用しているPE-GPTアプリケーションを、Amazon BedrockのClaudeモデルを使用するように移行することを目的としています。この移行により、AWSのマネージドサービスを活用し、より柔軟なモデル選択とコスト最適化を実現します。

## 要件

### 要件 1

**ユーザーストーリー:** PE-GPTユーザーとして、OpenAI GPTの代わりにAmazon BedrockのClaudeモデルを使用したい。これにより、AWSのマネージドAIサービスの恩恵を受け、潜在的により良いコスト効率を実現したい。

#### 受け入れ基準

1. アプリケーションが開始されたとき、システムはOpenAIクライアントの代わりにAmazon Bedrockクライアントを初期化すること
2. ユーザーがメッセージを送信したとき、システムはBedrock API経由でClaudeモデルを使用してレスポンスを生成すること
3. RAGシステムがドキュメントを処理するとき、システムは埋め込みとチャット機能にClaudeモデルを使用すること
4. Bedrock APIが利用できない場合、システムは適切なエラーメッセージをユーザーに表示すること

### 要件 2

**ユーザーストーリー:** 開発者として、Claudeで既存のRAG機能を維持したい。これにより、専門知識ベースの統合が継続してシームレスに動作するようにしたい。

#### 受け入れ基準

1. RAGシステムがドキュメントを読み込むとき、システムはドキュメント処理とインデックス化にClaudeモデルを使用すること
2. 複数のエージェントが初期化されるとき、各エージェントはBedrock経由でClaudeモデルを使用すること
3. チャットエンジンが作成されるとき、同じインターフェースを維持しつつClaudeバックエンドを使用すること
4. 類似性検索が実行されるとき、システムはベクトル操作にClaude埋め込みを使用すること

### 要件 3

**ユーザーストーリー:** システム管理者として、適切なAWS認証情報と設定管理を行いたい。これにより、Bedrock統合が安全で設定可能になるようにしたい。

#### 受け入れ基準

1. アプリケーションが開始されるとき、システムは適切な認証情報チェーンを使用してAWSで認証すること
2. Bedrockクライアントが初期化されるとき、システムは設定可能なAWSリージョン設定を使用すること
3. AWS認証情報が不足している場合、システムはセットアップ手順を含む明確なエラーメッセージを提供すること

### 要件 4

**ユーザーストーリー:** PE-GPTユーザーとして、同じユーザーインターフェースと機能を維持したい。これにより、移行が透明で私のワークフローを中断しないようにしたい。

#### 受け入れ基準

1. アプリケーションが実行されるとき、ユーザーインターフェースは現在の実装と同一であること
2. ユーザーがチャットで対話するとき、レスポンスの品質と形式が維持または改善されること
3. 設計フロープロセスが実行されるとき、既存のすべての機能が変更なしで動作すること

### 要件 5

**ユーザーストーリー:** 開発者として、後方互換性と簡単なロールバックオプションを持ちたい。これにより、変更を安全にデプロイし、必要に応じて元に戻すことができるようにしたい。

#### 受け入れ基準

1. 設定が行われるとき、システムは設定を通じてOpenAIとBedrockの切り替えをサポートすること
2. デプロイメントが発生するとき、システムは可能な限り既存の環境変数パターンを維持すること
3. ロールバックが必要な場合、システムはOpenAI実装への簡単な切り替えを許可すること
4. テスト時、両方の実装が同じ環境でテスト可能であること

### 要件 6

**ユーザーストーリー:** 開発者として、Bedrock統合の適切なエラーハンドリングとログ記録を行いたい。これにより、問題を効果的にトラブルシューティングできるようにしたい。

#### 受け入れ基準

1. Bedrock API呼び出しが失敗したとき、システムは詳細なエラー情報をログに記録すること
2. レート制限に達したとき、システムは指数バックオフを伴う適切な再試行ロジックを実装すること
3. 認証が失敗したとき、システムは認証情報セットアップに関する具体的なガイダンスを提供すること
4. モデルレスポンスが不正な形式の場合、システムは適切に処理し、フォールバックレスポンスを提供すること

## 質問と回答

### [Question 1] 
現在使用しているOpenAIモデル（gpt-4-0125-preview）に対応するBedrockのClaudeモデルはどれを使用しますか？

**[Answer 1]**
Claude Haiku 4.5, Claude 3.7 Sonnet, Claude 3.5 Sonnet v2 を使えるようにしてください。

### [Question 2]
AWS認証情報の管理方法について、環境変数、IAMロール、AWS CLIプロファイルのうち、どの方法を優先しますか？

**[Answer 2]**
実行環境のクレデンシャルを利用してください

### [Question 3]
現在のRAGシステムで使用している埋め込みモデル（OpenAIの埋め込みモデル）をBedrockの埋め込みモデル（Amazon Titan Embeddings等）に変更する必要がありますか？

**説明:** RAGシステムでは、ドキュメントをベクトル化するための埋め込みモデルと、チャット応答を生成するためのLLMの2つのモデルが使用されています。現在はOpenAIの埋め込みモデルを使用していますが、Claudeに移行する際に埋め込みモデルもAWSのものに統一するか、OpenAIの埋め込みモデルを継続使用するかを決める必要があります。

**[Answer 3]**
Bedrock の Titan のモデルを利用してください

### [Question 4]
移行期間中、OpenAIとBedrockの両方をサポートする設定切り替え機能は必要ですか？

**[Answer 4]**
Bedrockのみでよいです

### [Question 5]
Bedrockの利用可能リージョンに制限はありますか？（例：us-east-1、us-west-2等）

**[Answer 5]**
us-east-1

### [Question 6]
現在のStreamlitアプリケーションの設定画面でBedrockの設定（リージョン、モデル選択等）を変更できるようにする必要がありますか？

**[Answer 6]**
不要です
